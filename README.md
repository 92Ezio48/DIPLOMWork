# SkyFitnessPro

SkyFitnessPro — дипломный проект: интерактивная платформа для онлайн-тренировок, личного фитнес-роста, и ведения курсов.

## 🚀 Функционал

- Регистрация и вход по e-mail и паролю
- Работа с курсами (создание, просмотр, прохождение)
- Просмотр тренировок с видеоинструкциями
- Трекер выполнения упражнений

## 🛠️ Технологии

- Next.js 14 (App Router)
- React
- TypeScript
- SCSS-модули
- Express (backend), MongoDB
- JWT auth
- Axios

## 📥 Установка

1. Клонируй репозиторий:

   ```bash
   git clone https://github.com/yourname/skyfitnesspro.git
   cd skyfitnesspro
   ```

2. Установи зависимости:

   ```bash
   npm install
   ```

3. Запусти backend (нужен отдельный запуск, если есть):

   ```bash
   cd backend
   npm install
   npm start
   ```

4. Запусти frontend:

   ```bash
   cd frontend
   npm run dev
   ```

## 🏁 Запуск

Открой [http://localhost:3000](http://localhost:3000) в браузере.
